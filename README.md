# Coral Pop – Game Design Document

A tap-to-blast casual puzzle game set under the sea. The document covers the first 50 levels and opens with an analysis of Royal Match and Toon Blast.

- **Interactive version:** `index.html` (served with GitHub Pages; filters work in the browser)
- **PDF version:** [`Coral_Pop_GDD.pdf`](Coral_Pop_GDD.pdf)

`index.html` is a single self-contained file: all images are embedded, so it also works offline when downloaded and opened in Chrome or Edge.

**Visuals.** All game art was modeled, textured and rendered in Blender, based on references from open-source (CC0 and CC BY) sources. Required attributions: Finn's character reference was generated with Meshy (CC BY 4.0); the puffer fish, clownfish and chest started from Quaternius models (CC0).

Royal Match, Toon Blast, Royal Kingdom and Match Villains are studied for mechanic types only; no names, art or levels are reused.
